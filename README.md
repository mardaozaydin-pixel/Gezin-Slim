# GEZINSLIM

- 💰 Budget management
- 🎯 Savings goals
- 📊 Expense tracking
- 👨‍👩‍👧‍👦 Family planning
- 🍽️ Meal planner
- 🤖 AI assistant
- 📱 Mobile-first design

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Supabase
- OpenAI
